# APES Unit 1: The Living World

Interactive slides and student activities for AP Environmental Science Unit 1 (Topics 1.1–1.11).
Three classes: 2 h + 2 h + 1 h. 58 slides, 16 activities. One file, no server, no install.

## Links
- **Students:** `https://YOUR-USERNAME.github.io/REPO-NAME/`
- **Teacher (slides + results):** `https://YOUR-USERNAME.github.io/REPO-NAME/#teacher`

## Put it on GitHub Pages
1. Create a new public repository on GitHub (for example `apes-unit1`).
2. Upload `index.html`, `.nojekyll` and this `README.md` (Add file → Upload files → Commit).
3. Go to **Settings → Pages**. Under *Build and deployment*, choose **Deploy from a branch**, branch **main**, folder **/(root)**. Save.
4. Wait about 1 minute. Your site is at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## In class
1. Open the teacher link (ends with `#teacher`) and share your screen in ClassIn.
2. Paste the student link into the ClassIn chat.
3. On an activity slide, tell students which activity to open (A1, A2…).
4. At the end of each activity, each student gets a code like `#A3 Lily 11/13 x7k2` and pastes it into the ClassIn chat.
5. Copy the whole chat → **Class monitor** → paste → **Add codes**. Scores appear in the gradebook and on each activity slide.

## Notes
- Codes and progress are saved in each browser (localStorage), not online. Use the same browser for the whole unit.
- Anyone who knows the `#teacher` link, or reads the page source, can see the slides and answer keys. Don't share the teacher link with students.
- To edit text, open `index.html` on GitHub and click the pencil icon. Activities are in the `ACTS` list.
